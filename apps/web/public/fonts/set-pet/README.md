# «ست پت» text-print fonts

Self-hosted (no third-party font CDN) for the Set Pet text prints (owner, issue #368 P23: text in three fonts).
Loaded only by `features/set-pet/set-pet.css`, i.e. only on Set Pet pages.

| amiri-arabic-700.woff2, amiri-latin-700.woff2 | Amiri 700 | SIL Open Font License 1.1 (OFL-Amiri.txt) | @fontsource/amiri 5.1.0 |

The third font is the site's own Vazirmatn (lib/font-assets).
