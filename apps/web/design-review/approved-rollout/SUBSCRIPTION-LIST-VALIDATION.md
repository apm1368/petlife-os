# اشتراک خانواده‌ها — شواهد QA

مبنای کد `55fbb58ba0b6a66d62a4e48e6c71a97d72b72b6a`؛ main هنگام شروع `5c1fc12f6be05fbd638f89007d9623cf5e333e26`.

نقص قابل تکرار: پاسخ API با total=51 و pageSize=50 در رابط قبلی کنترل صفحهٔ بعد نداشت. پاسخ دیررس فیلتر قبلی می‌توانست دادهٔ فیلتر تازه را جایگزین کند؛ خطای فیلتر نیز ردیف‌های قبلی را پنهان نمی‌کرد. سه تست افزوده روی کد مبنا شکست خوردند؛ پس از اصلاح، شش تست فهرست و چهار تست جزئیات موفق‌اند. آزمون‌های قبلی حذف یا ضعیف نشده‌اند.

مرورگر Chromium واقعی، fa/en و عرض‌های ۳۹۰/۱۴۴۰: چهار تصویر قبل؛ پس از اصلاح فهرست/صفحهٔ دوم، خالی و خطای کنترل‌شده. صفحهٔ بعد باید GET با page=2 بفرستد. خطای کنترل‌شده 503 مجاز است؛ pageerror، شکست بارگذاری دارایی و اسکرول افقی مجاز نیست. جزئیات درخواست‌ها و دارایی‌های `/_next/static` در JSON همراه تصاویر است. قاب و رنگ‌های پوستهٔ مصوب ادمین حفظ شده‌اند؛ این بسته طراحی تازه‌ای جایگزین مرجع نمی‌کند.

بازاجرا از ریشهٔ مخزن با Next روی localhost:3035:

```sh
QA_STAGE=after QA_MODE=list QA_EVIDENCE_DIR=/tmp/subscription-qa python apps/web/design-review/approved-rollout/browser-subscription-list.py
# QA_MODE=empty و QA_MODE=error نیز اجرا شوند.
```

داده‌ها مصنوعی و فقط روی loopback هستند. مرورگر هیچ POST/PATCH/DELETE نمی‌فرستد. این بررسی، API/پایگاه دادهٔ واقعی، ورود زنده یا مجوزهای مالی را تأیید نمی‌کند؛ کنترل موجود `subscription.view` در سرور تغییر نکرده است. انتشار جدید، migration و آزمون مالی زنده انجام نشده‌اند. CI و وضعیت ادغام باید جدا در PR/Issue #4 ارزیابی شوند.

نتیجهٔ نهایی محلی: ۱۲ حالت بعد و چهار تصویر قبل ثبت شدند؛ overflow/pageerror/درخواست شکست‌خورده صفر و تمام دارایی‌های ثبت‌شده ۲۰۰ هستند. تنها console error مجاز، پاسخ مصنوعی 503 در حالت خطاست. typecheck و lint موفق‌اند (سه هشدار از قبل موجود). کلیدهای fa/en برابرند. یک اجرای اولیهٔ ابزار به‌علت انتخاب مبهم h1/h3 در حالت خطا متوقف شد؛ selector به heading سطح ۱ اصلاح و هر سه حالت کامل بازاجرا شدند.
