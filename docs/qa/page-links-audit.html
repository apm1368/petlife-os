فهرست صفحات برای بازبینی

۸۵ مسیر ثابت × دو زبان: همه HTTP 200. همچنین ۶۹ مسیر جزئیات نیازمند شناسه واقعی.

HTTP 200 به معنی سالم‌بودن API یا قابل‌استفاده‌بودن صفحه پس از ورود نیست. صفحه‌های خصوصی نیازمند ورود و نقش مناسب هستند. صفحات پویا از فهرست مربوط باز می‌شوند؛ لینک ساختگی ایجاد نشده است.
