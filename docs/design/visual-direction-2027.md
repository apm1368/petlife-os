# PET LIFE — جهت بصری ۲۰۲۷ (اپ محصول، بدون لندینگ)

این سند مستقیم به توکن‌ها و کلاس‌های کد نگاشت می‌شود. هر تصمیم یک نام توکن یا primitive دارد.
توکن‌ها: `packages/design-tokens/css/tokens.css` و `typography.css` — primitiveهای چیدمان: `apps/web/app/globals.css` بخش «VISUAL FOUNDATION».

## Audit — KEEP / REFINE / REPLACE

| حوزه | وضعیت قبلی | تصمیم |
|---|---|---|
| فونت | Vazirmatn / Inter | KEEP |
| رنگ سطح‌ها | خاکستری‌سبز سرد (#faf9f6 / #f5f3ee / سفید) | REPLACE → کاغذ گرم + سنگ |
| سبز برند | #17633f تک‌رنگ همه‌جا | REFINE → جنگلی عمیق + خزه + سبز طبیعی، نعنایی فقط برای state ملایم |
| رنگ دوم | بنفش AI | REFINE → آلویی ملایم، کبالت فقط برای تعامل محدود |
| تیره | خاکستری آبی (#121416) | REPLACE → زغالی گرم، نه مشکی خالص |
| radius | 8 / 12 / 20 | REPLACE → 6 / 10 / 14؛ گردی بزرگ فقط برای تصویر پت |
| سایه | سایهٔ جدا در هر جزء | REPLACE → دو سطح سایهٔ توکنی، بیشتر border و تضاد سطح |
| مقیاس تایپ | ناقص (title 2rem، section 1.25rem) | REFINE → ۹ نقش ثابت |
| motion | dur-1/2/3 بدون زبان مشخص | REFINE → سه زمان + دو منحنی، بدون bounce |
| پوستهٔ اپ | هدر + mega + تب‌بار موبایل | REFINE |
| داشبورد | کارت سبز گرادیانی + دیوار کارت | REPLACE → نوار هویت سرمقاله‌ای + فضای کار دوستونه |
| فهرست‌ها/ردیف‌ها | row-list، care-row، disc-row | KEEP و یکپارچه به `pl-row` |
| کارت | همه‌جا (member-home__card، experience-card) | REPLACE → section تخت با divider؛ کارت فقط برای شیء مستقل |

## اصول
1. **سرمقاله‌ای، نه داشبورد قالبی:** عنوان قوی، فضای خالی، divider به‌جای کادر.
2. **رنگ = سلسله‌مراتب:** سطح کاغذ برای صفحه، سطح بالا برای چیزی که کاربر رویش کار می‌کند، سطح معکوس (جنگلی تیره) فقط برای یک نوار هویت در هر صفحه.
3. **کارت فقط برای شیء مستقل:** نوبت، سفارش، پت. بخش‌ها تخت‌اند.
4. **تصویر پت قوی:** بزرگ‌ترین عنصر بصری صفحه‌های پت، عکس خود پت است.
5. **حرکت سریع و هدفمند:** ۱۲۰ تا ۲۶۰ میلی‌ثانیه، بدون پرش.

## فاصله، radius، سایه، لایه
- فاصله: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 56 · 72 (`--space-1` تا `--space-10`).
- radius: `--radius-sm` 6، `--radius-md` 10، `--radius-lg` 14، `--radius-media` 18 (فقط عکس پت/رسانه).
- سایه: `--shadow-1` برای جزء شناور کوچک، `--shadow-2` برای منو، drawer و dialog. هیچ سایهٔ دیگری مجاز نیست.
- لایه: `--z-sticky` 30، `--z-header` 40، `--z-menu` 50، `--z-drawer` 60، `--z-dialog` 70، `--z-toast` 80.

## Motion
- زمان‌ها: `--dur-1` 120ms (hover/press)، `--dur-2` 180ms (منو، تب، انتخاب)، `--dur-3` 260ms (drawer، تغییر مرحله).
- منحنی‌ها: `--ease-out` cubic-bezier(.2,.8,.2,1)، `--ease-emph` cubic-bezier(.16,1,.3,1).
- همه با `prefers-reduced-motion` خنثی می‌شوند (قاعدهٔ سراسری موجود).

## ترکیب صفحه — primitiveها
| primitive | کاربرد |
|---|---|
| `pl-page` | ستون اصلی صفحه، full-width تا 1600px با gutter |
| `pl-band` | نوار هویت سرمقاله‌ای بالای صفحه (پت، ارائه‌دهنده) |
| `pl-split` | چیدمان 12 ستونه: اصلی 8 + کناری 4 (≥1100px) |
| `pl-section` + `pl-section__head` | بخش تخت با عنوان و اکشن، جداشده با divider |
| `pl-row` | ردیف داده: عنوان، متادیتا، وضعیت، فلش |
| `pl-meta` | ردیف متادیتای خطی با جداکننده |
| `pl-chip` | برچسب وضعیت/فیلتر کوچک |
| `pl-object` | کارت برای شیء مستقل (نوبت، سفارش) |
| `pl-actions` | ردیف اکشن‌های بخش |

## الهام (نه کپی)
- **Linear:** تراکم و divider به‌جای کادر.
- **Airbnb:** تصویرمحوری و پنل رزرو چسبان.
- **Stripe Dashboard:** سلسله‌مراتب تایپ و ردیف داده.
- **Apple Health:** آرامش در دادهٔ پزشکی.
- **Arc / Raycast:** سرعت حرکت و فوکوس کیبورد.

## ضدالگوها (رد شود)
- کارت داخل کارت، دیوار کارت
- گرادیان پرحجم و رنگ‌های پاستلی برای هر بخش
- radius بالای 14px روی سطوح عملیاتی
- سایهٔ بزرگ روی بخش‌ها
- آیکون کنار هر برچسب
