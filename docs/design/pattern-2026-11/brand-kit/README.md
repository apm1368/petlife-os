# لوگوی اپت لایف

نشانه از سه حرف opl ساخته شده است: حرف o یک گربه است (گوش‌ها، چشم‌ها و بینی زرد)، حرف p یک سگ (گوش آویزان زرد و پوزه) و حرف l جوانه‌ای برای «زندگی». در نسخهٔ فارسی کنار نشانه «اپت لایف» نوشته می‌شود و در انگلیسی، آلمانی و اسپانیایی «opetlife».

## پوشه‌ها
- `svg/` فایل‌های برداری. متن‌ها به مسیر (outline) تبدیل شده‌اند و به فونت نیاز ندارند.
  - `mark-color` رنگی، `mark-white` برای زمینهٔ تیره، `mark-forest` و `mark-black` و `mark-mono_white` تک‌رنگ.
  - `lockup-fa` و `lockup-fa-tagline` افقی فارسی (با و بدون شعار)، نسخه‌های `-white` برای زمینهٔ تیره.
  - `lockup-en` افقی لاتین، `stacked-fa` عمودی فارسی.
  - `app-icon`، `favicon`، `maskable-icon`، `social-card`.
- `png/` همان طرح‌ها در اندازه‌های آماده (نشانه ۲۵۶ تا ۱۰۲۴، لاک‌آپ ۶۰۰ تا ۲۴۰۰، آیکون اپ ۱۲۰ تا ۱۰۲۴، فاوآیکن ۱۶ تا ۶۴، تصویر اشتراک‌گذاری ۱۲۰۰×۶۳۰).
- `favicon.ico` شامل ۱۶، ۳۲ و ۴۸ پیکسل.
- `site.webmanifest` و `head-snippet.html` برای نصب روی سایت.

## قواعد استفاده
- فضای خالی دور لوگو دست‌کم به اندازهٔ ارتفاع حلقهٔ «o» باشد.
- کمترین اندازه: نشانه ۲۴ پیکسل ارتفاع؛ زیر آن از آیکون اپ یا فاوآیکن استفاده شود.
- روی زمینهٔ تیره فقط نسخهٔ `-white` یا تک‌رنگ سفید.
- لوگو را نچرخانید، کش ندهید، سایه یا گرادیان اضافه نکنید و رنگ گوش و جوانه را عوض نکنید.
- حروف را جدا از هم استفاده نکنید، مگر در توضیح ساختار.
