# ریلز

هر صفحهٔ اصلی یک ریلز کوتاه و بی‌کلام دارد که خدمات همان صفحه را با تصویرسازی متحرک، موسیقی و زیرنویس معرفی می‌کند.

## قالب

- قاب عمودی ۹:۱۶ (فضای طراحی ۳۶۰×۶۴۰)، با گوشهٔ ۳۶ پیکسل و حاشیهٔ سفید ۱۰ پیکسلی.
- ۶ تا ۱۰ صحنه، هر صحنه ۳ ثانیه؛ کل ریلز ۱۸ تا ۳۰ ثانیه.
- صحنهٔ اول: ساخته‌شدن لوگو (حلقهٔ o کشیده می‌شود، گوش‌ها و چشم‌ها می‌پرند، p بالا می‌آید، جوانهٔ l می‌روید) و نام برند به زبان صفحه.
- صحنهٔ آخر: لوگو روی سبز، نام برند، opetlife.ir و دکمهٔ زرد همان صفحه.
- محتوای تصویر بین y=۹۰ و y=۴۶۰؛ پایین قاب برای زیرنویس، بالا برای نوار پیشرفت و برچسب فصل.

## زیرنویس

- یک جملهٔ کوتاه (حداکثر ۹ کلمه) برای هر صحنه، کلمه‌به‌کلمه ظاهر می‌شود.
- در کپسول تیرهٔ نیمه‌شفاف، متن سفید، وسط‌چین.
- برای هر زبان جدا نوشته می‌شود (fa، en، de، es) و از فایل‌های پیام می‌آید، نه از تصویر.

## موسیقی

- یک قطعهٔ بی‌کلام با مجوز، شاد و آرام (حدود ۹۰ تا ۱۰۰ ضرب در دقیقه)، بلندی حدود ‎-18 LUFS.
- فقط با کلیک کاربر روی «پخش با موسیقی» شروع می‌شود. دکمه‌های مکث و بی‌صدا همیشه دیده می‌شوند.

## واژگان حرکت

| نام | کار | زمان |
|---|---|---|
| pop | ظاهر شدن با کمی جهش | ۷۰۰ms |
| rise | بالا آمدن از ۴۰ پیکسل پایین‌تر | ۷۰۰ms |
| draw | کشیده شدن خط یا حلقه | ۱۰۰۰ms |
| drop | افتادن از بالا و نشستن | ۸۵۰ms |
| fade | محو شدن به داخل | ۶۰۰ms |
| float | شناور آرام، تکراری | ۲٫۴s |
| spin | چرخش آرام، تکراری | ۷s |
| ring | تکان زنگ | ۱٫۳s |
| pulse | موج رادار | ۱٫۸s |
| up | بالا رفتن حباب یا قلب | ۲٫۸s |
| twinkle | چشمک ستاره | ۱٫۲s |
| beat | تپش قلب | ۱s |

هر صحنه حداکثر سه نوع حرکت ورود دارد و ورودها با فاصلهٔ ۱۵۰ تا ۲۰۰ میلی‌ثانیه پشت هم می‌آیند.

## پیاده‌سازی

- جزء React با فهرست صحنه‌ها؛ هر صحنه یک SVG برداری است و متنش از فایل پیام می‌آید.
- بدون فایل ویدیو؛ سبک و قابل ترجمه.
- کنار ریلز فهرست فصل‌ها با شمارهٔ صحنه؛ کلیک روی هر فصل همان صحنه را پخش می‌کند.
- با کاهش حرکت: صحنه‌ها بدون حرکت و با دکمه‌های قبلی/بعدی.
