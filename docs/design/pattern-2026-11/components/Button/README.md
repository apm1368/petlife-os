# Button

دکمهٔ نرم و کپسولی اپت لایف در چهار گونه: اصلی، گرم، نرم و خطی.

- **اصلی** (`forest` با متن `on-forest`): مهم‌ترین کار هر بخش؛ فقط یکی در هر بخش.
- **گرم** (`sun` با متن `on-sun`): کار فوری اما مهربان، مثل «دیدن آگهی‌های گمشده».
- **نرم** (`mint` با متن `forest`): کار دوم، مثل «ورود».
- **خطی** (حاشیهٔ `line-2`): کار سوم، مثل «ورود همکار».

اندازه‌ها: عادی ۵۲، کوچک ۴۰ (هدر)، بزرگ ۶۰ پیکسل (دعوت نهایی). گوشه `radius-pill`، سایه `shadow-button`، روی hover دو پیکسل بالا و `shadow-button-hover`، روی کلیک `scale(.97)`. فوکوس: حلقهٔ ۳ پیکسلی `sun` با فاصلهٔ ۳ پیکسل.

متن دکمه با فعل شروع می‌شود و یک تا سه کلمه است. پیکان فقط برای رفتن به صفحهٔ دیگر؛ در فارسی رو به چپ.
