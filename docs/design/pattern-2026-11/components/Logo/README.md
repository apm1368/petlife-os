# Logo

نشانهٔ opl اپت لایف: حرف o گربه، p سگ و l جوانهٔ زندگی؛ کنارش «اپت لایف» در فارسی و «opetlife» در بقیهٔ زبان‌ها.

- حروف `forest`، گوش سگ و بینی گربه `sun`، جوانه `leaf`، بینی سگ `ink`. روی زمینهٔ تیره حروف `on-forest` و بینی سگ `sun`.
- فضای خالی دور لوگو دست‌کم به اندازهٔ ارتفاع حلقهٔ o. کمترین ارتفاع نشانه ۲۴ پیکسل؛ کوچک‌تر از آن آیکون اپ یا فاوآیکن.
- آیکون اپ و فاوآیکن: نشانهٔ سفید روی مربع گرد `forest` (گوشهٔ ۲۲٪).
- نچرخانید، کش ندهید، سایه یا گرادیان نزنید، رنگ گوش و جوانه را عوض نکنید و حروف را جدا نکنید.
- فایل‌های SVG (متن تبدیل‌شده به مسیر)، PNG، favicon.ico و تصویر اشتراک‌گذاری در بستهٔ لوگو تحویل شده‌اند.
