# Header

هدر شیشه‌ای و روشن مشترک همهٔ صفحه‌های عمومی، با لوگو، منوی پنج دنیا، انتخاب زبان و دکمه‌های نرم.

- زمینه `paper` با ۸۶٪ شفافیت و blur ۱۴ پیکسل؛ چسبان بالای صفحه. بعد از اسکرول، خط `line` و سایهٔ ملایم می‌گیرد.
- راست (در فارسی): نشانهٔ opl و «اپت لایف» با شعار کوچک «یک جهان برای حیوانات خانگی».
- وسط: خانه، خدمات (منوی کشویی با پنج پرسش و «همهٔ خدمات»)، دامپزشکی، دربارهٔ ما، برای همکاران. مورد فعال با زمینهٔ `mint`.
- چپ: انتخاب زبان (فارسی، English، Deutsch، Español)، حالت نمایش ساده (Aa)، «همکاران» (خطی)، «ورود» (نرم)، «عضویت» (اصلی). کاربر واردشده به‌جای دو دکمهٔ آخر «داشبورد من» می‌بیند.
- زیر ۱۰۶۰ پیکسل: فقط لوگو، زبان، «عضویت» و دکمهٔ منو؛ منو یک برگهٔ کشویی با همهٔ پیوندهاست.
- همهٔ کنترل‌ها کپسولی (`radius-pill`) و دکمه‌های دایره‌ای ۴۲ پیکسلی.
