# منابع اقامت خارجی pet-friendly — شواهد کشف منبع (TRAVEL-EXT)

**تاریخ بررسی:** ۲۰۲۶-۱۰-۰۹ (۱۷ مهر ۱۴۰۵).
**شیوه‌ی بررسی:**
- فقط درخواست‌های خواندنی و کم‌حجم.
- User-Agent صادقانه: `PetLifeBot/1.0 (+http://185.231.112.154/)`.
- بدون دور زدن هیچ محافظتی.

| پرسش | جاباما (jabama.com) | علی‌بابا (alibaba.ir) |
|---|---|---|
| API رسمی عمومی | پیدا نشد | پیدا نشد |
| فید مجاز / برنامه‌ی همکاری عمومی | پیدا نشد | پیدا نشد |
| robots.txt از سرور PET LIFE | **HTTP 403 «Request Rejected»** (شناسه‌ی پشتیبانی 16455553345738847478) | **HTTP 403** با صفحه‌ی «ترافیک غیرمعمول» (شناسه‌ی پشتیبانی 15227085445141492039) |
| صفحه‌ی اصلی از شبکه‌ی دیگر | در دسترس است، ولی فیلتر حیوان خانگی روی آن دیده نشد | — |
| فیلتر pet-friendly | **تأیید نشد** | **تأیید نشد** |
| شناسه و URL پایدار هر آگهی | به‌دلیل مسدود بودن، قابل بررسی نشد | به‌دلیل مسدود بودن، قابل بررسی نشد |
| نکته | — | خود علی‌بابا اعلام کرده اقامتگاه‌های ثبت‌شده در جاباما خودکار در علی‌بابا هم فهرست می‌شوند؛ این برای تطبیق آگهی‌های تکراری بین دو منبع مهم است. |

## نتیجه
- **دریافت خودکار:** برای هر دو منبع `BLOCKED_EXTERNAL` است. WAF هر دو منبع درخواست‌های شناسه‌دار سرور ما را رد می‌کند.
  - طبق قواعد، تغییر User-Agent، پروکسی چرخشی، مرورگر جعلی یا عبور از CAPTCHA انجام نمی‌شود.
- **حالت فعلی منبع:**
  - `mode=MANUAL`: کارمند مجاز می‌تواند آگهی را با شواهد منبع ثبت کند. این شامل URL صفحه‌ی منبع، نوع و متن شاهد پذیرش حیوان، و تاریخ مشاهده است؛ قیمت هم برای تاریخ‌های مشخص و با زمان مشاهده، به‌صورت اختیاری.
  - هیچ آگهی‌ای خودکار ساخته نمی‌شود.
- **بررسی دوباره:** `POST /api/admin/travel/external/sources/{code}/probe` فقط یک درخواست robots.txt می‌فرستد.
  - اگر روزی دسترسی مجاز داده شود، بعد از پیاده‌سازی adapter واقعی، `automationStatus` می‌تواند `SUPPORTED` شود.
- **مانع خارجی برای تصمیم مالک:**
  - گرفتن API یا فید مجاز از جاباما و علی‌بابا؛
  - یا هر قرارداد همکاری یا affiliate.
  - تا آن زمان هیچ ادعای همکاری، affiliate یا «موجودی زنده» مطرح نمی‌شود.

## منابع آینده
Otaghak، Jajiga و Shab در جدول منابع با وضعیت `DISABLED / NOT_SUPPORTED` ثبت شده‌اند و هنوز بررسی نشده‌اند. اضافه کردن هرکدام فقط یک adapter جدید لازم دارد و schema تغییر نمی‌کند.

### تصمیم
- **وضعیت خودکارسازی:** `automationStatus=NOT_SUPPORTED` و `health=DEGRADED`؛ فقط ثبت دستی.
  - مسدودسازی دیگر دائمی نیست، پس وضعیت `BLOCKED_EXTERNAL` تغییر کرد.
  - ولی کانال مجاز و منتشرشده‌ای وجود ندارد: نه API عمومی، نه فید، نه فیلتر عمومی حیوان خانگی.
- **endpointهای داخلی:** استفاده‌ی خودکار از endpointهای مستندنشده‌ی داخلی سایت دیگران، در حالی که شرایط استفاده معلوم نیست و فیلتر حیوان خانگی تأیید نشده، تصمیمی **حقوقی و تجاری برای مالک** است. ما خودمان آن را انجام نمی‌دهیم.
- **راه پیشنهادی:** درخواست رسمی API، فید یا همکاری affiliate از جاباما و علی‌بابا.
  - با دسترسی مجاز، یک adapter جدید پیاده می‌شود و `automationStatus=SUPPORTED` می‌شود.
  - schema و رابط‌ها تغییری لازم ندارند.

## تصمیم جدید مالک — ۲۰۲۶-۱۰-۱۱: دریافت روزانه‌ی داده‌ی عمومی برای نسخه‌ی نمایشی تأیید شد
- **دامنه‌ی تأیید:** دریافت روزانه‌ی داده‌ی عمومی جاباما و علی‌بابا، فقط برای محیط demo/test فعلی.
  - مجاز: صفحات عمومی، JSON-LD، sitemap، و endpointهای JSON که خود سایت در مرورگر عمومی و بدون login صدا می‌زند.
  - برچسب این endpointها `UNOFFICIAL_PUBLIC_WEB_ENDPOINT` است، نه `PARTNER_API`.
- **مرز:** هیچ دور زدن CAPTCHA، احراز هویت، anti-bot یا rate-limit؛ هیچ proxy rotation و هیچ token خصوصی.
- **قرارداد:** هیچ قرارداد، API رسمی یا affiliate وجود ندارد. API و UI همیشه `partnership: NONE` و `affiliateStatus: NONE` برمی‌گردانند.

### شواهد کشف علی‌بابا (۲۰۲۶-۱۰-۱۱)
- **صفحه‌ها:** صفحات `/accommodation/*` اسکلت SPA هستند.
- **bundle عمومی** (`cdn.alibaba.ir/h2/desktop/*.js`) این endpointها را بدون نیاز به ورود صدا می‌زند:
  - `GET https://ws.alibaba.ir/api/v1/accom/landing/landing-pages/path/{slug}`
    - **مشاهده شد:** HTTP 200، JSON، بدون auth، با `unauthorizedRequest:false`.
    - خروجی شامل `availableSearch.destination` (مثل `city-ramsar`)، `minPrice` (ریال، یعنی FROM_PRICE) و فیلترها است.
    - یک نمونه‌ی پاک‌سازی‌شده در `adapters/__fixtures__/alibaba-landing-ramsar-villa.json` ذخیره شد.
  - `POST https://ws.alibaba.ir/api/v2/accommodation/Available/Search`
    - بدنه: `{pageSize, pageNumber, date:{startTime:{seconds}, endTime:{seconds}}, filters:{platform, guarantees:false}, location}`.
    - **مشاهده نشد:** ابزار توسعه‌ی Claude Code درخواست probe را رد کرد (`TOOL_PERMISSION_BLOCKED`).
    - این پاسخ منبع نیست. علی‌بابا هیچ 403 یا 429 برنگرداند.
  - `GET https://ws.alibaba.ir/api/v2/accommodation/Available/GetDetails/{id}`: هنوز امتحان نشده.
  - endpointهای wishlist و order به حساب کاربری نیاز دارند و خارج از دامنه‌اند.
- **وضعیت ثبت‌شده برای علی‌بابا:**
  - `sourceType = UNOFFICIAL_PUBLIC_WEB_ENDPOINT` و `accessStatus = TOOL_PERMISSION_BLOCKED`؛
  - adapter با `parserReady = false`.
  - **health check واقعی:** فقط landing endpoint، روزی یک‌بار، با یک درخواست.
- **parser:** نگاشت فیلدهای search و details عمداً نوشته نشده است. parser حدسی داده‌ی غلط منتشر می‌کند.
  - بعد از اولین پاسخ واقعی Search و GetDetails، parser و fixture آن اضافه می‌شوند.
  - بعد `automationStatus = SUPPORTED` و `mode = AUTOMATED` می‌شوند.
- **جاباما:** هنوز کشف نشده و adapter فقط robots.txt را بررسی می‌کند. ترتیب کشف: صفحه‌ی فهرست، بعد JSON داخل صفحه، بعد XHR عمومی.

### موتور مشترک (TRAVEL-SCRAPE-1..3) — آماده، بدون وابستگی به منبع
- **pacing:** یک درخواست در هر لحظه و فاصله‌ی تصادفی ۱.۵ تا ۳ ثانیه بین درخواست‌ها (برای هر منبع قابل تنظیم).
- **بودجه و امنیت درخواست:**
  - سقف درخواست در هر run؛
  - timeout سخت؛
  - سقف حجم پاسخ به‌صورت stream؛
  - SSRF-safe با allowlist، بررسی IP خصوصی و اعتبارسنجی هر redirect؛
  - User-Agent واقعی `PetLifeDemoTravelCrawler/1.0`.
- **خطاهای منبع:** پاسخ 403 یا CAPTCHA یعنی `BLOCKED` با circuit بسته به مدت ۲۴ ساعت و وظیفه‌ی `SOURCE_BLOCKED`. پاسخ 429 یعنی صبر به اندازه‌ی Retry-After. هیچ تلاش دوباره‌ای برای دور زدن نیست.
- **چرخه‌ی عمر آگهی:**
  - وضعیت‌ها: `DISCOVERED`، `ACTIVE`، `STALE` (بعد از ۲ run کامل که آگهی دیده نشده)، `SOURCE_REMOVED` (بعد از ۴ run) و `HIDDEN`؛
  - discovery ناقص یا run دارای anomaly هیچ آگهی‌ای را حذف نمی‌کند.
- **anomaly پارسر:** اگر تعداد آگهی‌ها کمتر از ۳۰٪ میانه‌ی ۵ run سالم اخیر باشد، run با `PARTIAL + anomaly` ثبت می‌شود، تغییر چرخه‌ی عمر اعمال نمی‌شود، و وظیفه‌ی `PARSER_ANOMALY` ساخته می‌شود.
- **snapshot و diff:**
  - snapshot (`external_stay_observations`) فقط وقتی ذخیره می‌شود که محتوا تغییر کرده باشد: نسخه‌ی normalized به‌اضافه‌ی گزیده‌ی خام حداکثر ۴KB که بعد از ۷ روز پاک می‌شود.
  - diff فیلدها با مقدار قبلی، مقدار جدید و run ثبت می‌شود.
- **سیاست حیوان خانگی:**
  - وضعیت‌ها: `CONFIRMED_ALLOWED`، `CONFIRMED_NOT_ALLOWED`، `AMBIGUOUS` و `UNKNOWN`، با تشخیص قطعی کلیدواژه‌های فارسی و تشخیص نفی در همان جمله.
  - ویلا، باغ یا اشاره به سگ در نظرات کاربران شاهد حساب نمی‌شود.
  - برای هر ادعا یک ردیف شاهد (excerpt کوتاه، مسیر، زمان) ذخیره می‌شود.
  - تغییر بین «مجاز» و «ممنوع» یعنی `PET_POLICY_CONFLICT` به‌اضافه‌ی یک وظیفه.
  - بررسی ادمین (`ADMIN_CONFIRMED`) بر مشاهده‌ی منبع مقدم است و مشاهده‌ی منبع جداگانه حفظ می‌شود.
- **قیمت:**
  - همیشه با زمینه ذخیره می‌شود: checkIn، checkOut، occupancy، ریال، observedAt و نوع `EXACT`، `FROM_PRICE` یا `UNKNOWN`.
  - برچسب تازگی: `FRESH` تا ۲۴ ساعت، `AGING` تا ۷۲ ساعت، `STALE` بعد از آن بدون نمایش عدد، و `UNKNOWN`.
  - پنجره‌های مشاهده‌ی روزانه: نزدیک‌ترین آخر هفته، و ۷، ۱۴ و ۳۰ روز بعد.
- **تکراری‌ها:** کاندیدهای تکراری بین منابع هرگز خودکار ادغام نمی‌شوند. با تأیید ادمین یک `CanonicalAccommodation` ساخته می‌شود.
