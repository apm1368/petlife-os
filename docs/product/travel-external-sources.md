# منابع اقامت خارجی pet-friendly — شواهد کشف منبع (TRAVEL-EXT)

**تاریخ بررسی:** ۲۰۲۶-۱۰-۰۹ (۱۷ مهر ۱۴۰۵).
**شیوه‌ی بررسی:**
- فقط درخواست‌های خواندنی و کم‌حجم.
- User-Agent صادقانه: `PetLifeBot/1.0 (+http://185.231.112.154/)`.
- بدون دور زدن هیچ محافظتی.

|---|---|---|

## نتیجه
- **دریافت خودکار:** برای هر دو منبع `BLOCKED_EXTERNAL` است. WAF هر دو منبع درخواست‌های شناسه‌دار سرور ما را رد می‌کند.
  - طبق قواعد، تغییر User-Agent، پروکسی چرخشی، مرورگر جعلی یا عبور از CAPTCHA انجام نمی‌شود.
- **حالت فعلی منبع:**
  - `mode=MANUAL`: کارمند مجاز می‌تواند آگهی را با شواهد منبع ثبت کند. این شامل URL صفحه‌ی منبع، نوع و متن شاهد پذیرش حیوان، و تاریخ مشاهده است؛ قیمت هم برای تاریخ‌های مشخص و با زمان مشاهده، به‌صورت اختیاری.
  - هیچ آگهی‌ای خودکار ساخته نمی‌شود.
- **بررسی دوباره:** `POST /api/admin/travel/external/sources/{code}/probe` فقط یک درخواست robots.txt می‌فرستد.
  - اگر روزی دسترسی مجاز داده شود، بعد از پیاده‌سازی adapter واقعی، `automationStatus` می‌تواند `SUPPORTED` شود.
- **مانع خارجی برای تصمیم مالک:**
  - گرفتن API یا فید مجاز از جاباما و علی‌بابا؛
  - یا هر قرارداد همکاری یا affiliate.
  - تا آن زمان هیچ ادعای همکاری، affiliate یا «موجودی زنده» مطرح نمی‌شود.

## منابع آینده
Otaghak، Jajiga و Shab در جدول منابع با وضعیت `DISABLED / NOT_SUPPORTED` ثبت شده‌اند و هنوز بررسی نشده‌اند. اضافه کردن هرکدام فقط یک adapter جدید لازم دارد و schema تغییر نمی‌کند.
