## مسیر انتشار (از ۱۲ نوامبر)

- build دیگر روی VPS انجام نمی‌شود. GitHub Actions نسخه را می‌سازد و در
  pre-release داخلی `deploy-builds` بارگذاری می‌کند. VPS آرشیو و checksum را از
  CDN انتشار GitHub دریافت می‌کند (#312، #323).
- deployها سریالی‌اند (`concurrency: deploy-vps`، بدون لغو اجرای در جریان). اجرای
  جدید منتظر می‌ماند تا deploy قبلی تمام شود و سقف SSH ۹۰ دقیقه است (#308).
- کش route هنگام deploy پاک می‌شود و smoke test صفحهٔ اصلی canonical را بررسی
  می‌کند، نه redirect `/fa` را.
- از ۱۳ نوامبر، تغییرها به‌صورت «release train» (A تا H) دسته‌بندی و با یک PR
  ادغام می‌شوند. PRهای تشکیل‌دهندهٔ هر train پس از ادغام train بسته می‌شوند
  (وضعیت CLOSED آن‌ها به معنای رد شدن نیست).

## قواعد ادامهٔ کار

1. فقط از `main` شاخه بگیرید و پس از CI سبز روی head نهایی، از مسیر عادی و محافظت‌شدهٔ GitHub به `main` ادغام کنید (TC-21).
2. قبل از اعلام انتشار، SHA خروجی `/api/health/version` باید با merge commit برابر باشد.
3. CI فقط روی `pull_request` و push به `stabilization/wave-1` اجرا می‌شود؛ PR را زود باز کنید تا e2e اجرا شود.
4. PR #59 عمداً خارج از مسیر ادغام است؛ فقط بخش‌های سازگار آن، در صورت نیاز، جداگانه وارد `main` شوند.
5. شاخه‌های unmerged قدیمی را بدون بررسی diff حذف نکنید.
6. عملیات حساس مالی (اصلاح کیف پول، حساب کارت‌به‌کارت جدید، بازپرداخت تکراری) همیشه تأیید نفر دوم می‌خواهد (FE-16، BO-14، PY-19).

### تعریف آماده‌بودن برای انتشار

یک مورد فقط وقتی `LIVE_VERIFIED` است که: CI روی head نهایی سبز باشد، به `main`
ادغام شود، migration امن در صورت نیاز اجرا شود، SHA خروجی
`/api/health/version` با SHA ادغام برابر باشد، و smoke test production موفق باشد.
تا قبل از این مراحل، وضعیت درست «آمادهٔ review» یا «آمادهٔ release» است، نه
«روی سایت».

## بررسی محلی و انتشار

```bash
pnpm install --frozen-lockfile
pnpm typecheck && pnpm lint && pnpm test
NEXT_PUBLIC_API_ORIGIN=http://localhost:4000 pnpm build
curl -fsS https://opetlife.ir/api/health/ready
curl -fsS https://opetlife.ir/api/health/version
```

برای جزئیات معماری و قراردادها، از `docs/product/` و منبع حقیقت داده یعنی
`apps/api/prisma/schema.prisma` استفاده کنید.
